= Configure o acesso à rede nas ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Por padrão, as ONTAP tools adicionam automaticamente todos os endereços IP descobertos do host ESXi à política de exportação, a menos que você configure o acesso à rede. Você pode modificar a política de exportação para permitir o acesso somente de endereços IP específicos; as operações de montagem falham para hosts ESXi excluídos.

.Passos
. Faça login no cliente vSphere.
. Selecione *NetApp ONTAP tools* na página de atalhos, na seção de plug-ins.
. No painel esquerdo das ferramentas ONTAP , vá para *Configurações* > *Gerenciar acesso à rede* > *Editar*.
+
Para adicionar vários endereços IP, separe a lista com vírgulas, intervalos, notação CIDR (Classless Inter-Domain Routing) ou uma combinação dos três.

. Selecione *Guardar*.
