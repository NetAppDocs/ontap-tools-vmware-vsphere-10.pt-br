= Associe um backend de armazenamento a uma instância do servidor vCenter nas ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Associe um backend de storage global, adicionado no ONTAP tools Manager, mas ainda não vinculado a uma instância específica do vCenter Server, a uma instância do vCenter Server. Para configurações do NetApp MetroCluster, associe também o cluster peer ao vCenter Server.

.Passos
. Inicie o Gerenciador de ferramentas do ONTAP a partir de um navegador da Web: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Faça login com as ferramentas do ONTAP para as credenciais de administrador do VMware vSphere fornecidas durante a implantação.
. Selecione *vCenter* na barra lateral.
. Selecione as reticências verticais ao lado da instância do vCenter Server à qual você deseja conectar aos storage backends.
. No menu suspenso, escolha o backend de armazenamento que você deseja associar à instância selecionada do vCenter Server.



NOTE: Para configurações NetApp MetroCluster, ao associar um cluster de backend de armazenamento, associe também o cluster correspondente ao vCenter Server.

.O que se segue?
As ONTAP tools associam o backend de storage selecionado à instância do vCenter Server, tornando-o disponível para operações de datastore nesse ambiente do vCenter Server.
