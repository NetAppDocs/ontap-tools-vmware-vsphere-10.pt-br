= Saiba mais sobre o console de manutenção das ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O console de manutenção das ONTAP tools for VMware vSphere permite gerenciar configurações de aplicativos, sistemas e redes.  Você pode atualizar senhas de administrador e de manutenção, gerar pacotes de suporte, configurar níveis de registro, gerenciar configurações de TLS e habilitar diagnósticos remotos.

Após implantar as ONTAP tools for VMware vSphere, se o console de manutenção não estiver acessível, instale as ferramentas VMware a partir do vCenter Server.  Faça login usando o `maint` Nome de usuário e senha definidos durante a implantação.  Use o *nano* para editar arquivos no console de manutenção ou no console de login de root.


NOTE: Você deve definir uma senha para `diag` o usuário ao ativar o diagnóstico remoto.

Você deve usar a guia *Resumo* das ferramentas do ONTAP implantadas para o VMware vSphere para acessar o console de manutenção. Quando você seleciona image:../media/launch-maintenance-console.gif["Botão Play (Reproduzir)"], o console de manutenção é iniciado.

|===


| *Menu Console* | *Opções* 


 a| 
Configuração da aplicação
 a| 
. Apresentar resumo do estado do servidor
. Alterar nível de LOG para serviços de ferramentas ONTAP
. Alterar sinalizador de validação de certificado




 a| 
Configuração do sistema
 a| 
. Reinicie a máquina virtual
. Desligue a máquina virtual
. Gerar token para redefinir a senha da interface do usuário do administrador
. Alterar fuso horário
. Aumentar o tamanho do disco de cadeia (/jail)
. Atualização
. Instale o VMware Tools
. Atualizar credenciais do vCenter
. Atualizar certificados de serviços do ONTAP tools




 a| 
Configuração de rede
 a| 
. Apresentar definições de endereço IP
. Exibir configurações de pesquisa de nome de domínio
. Altere as configurações de pesquisa de nome de domínio
. Apresentar rotas estáticas
. Alterar rotas estáticas
. Confirmar alterações
. Faça ping em um host
. Restaure as predefinições




 a| 
Suporte e Diagnóstico
 a| 
. Aceder ao shell de diagnóstico
. Ative o acesso de diagnóstico remoto
. Forneça credenciais do vCenter para backup
. Faça backup
