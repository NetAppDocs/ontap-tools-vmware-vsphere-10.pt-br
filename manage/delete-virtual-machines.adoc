= Limpe as configurações do VASA nas ferramentas ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Siga estes passos para concluir a limpeza do VASA nas ferramentas ONTAP.


NOTE: Remova todos os datastores vVols antes de iniciar a limpeza do VASA.

.Passos
. Abra  `\https://OTV_IP:8143/Register.html` para cancelar o registro do plug-in.
. Verifique se o plug-in não está mais disponível no vCenter Server.
. Desligue a máquina virtual (VM) do ONTAP tools for VMware vSphere.
. Excluir ferramentas do ONTAP para VM VMware vSphere.
