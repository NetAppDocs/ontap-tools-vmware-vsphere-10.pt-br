= Desinstale sua implantação do ONTAP tools for VMware vSphere
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Desinstalar o ONTAP tools for VMware vSphere exclui dados no appliance, então siga estas etapas para encerrar a implantação corretamente e evitar perda de dados inesperada.

.Passos
. Remova ou mova todas as máquinas virtuais das ferramentas do ONTAP para armazenamentos de dados gerenciados do VMware vSphere.
+
** Para remover as máquinas virtuais, consulte https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-virtual-machine-administration-guide-8-0/managing-virtual-machinesvsphere-vm-admin/adding-and-removing-virtual-machinesvsphere-vm-admin.html#GUID-376174FE-F936-4BE4-B8C2-48EED42F110B-en["Remover e Registrar novamente VMs e modelos de VM"]
** Para movê-los para um datastore não gerenciado, consulte  https://techdocs.broadcom.com/["Documentação técnica Broadcom"] para migrar máquinas virtuais com Storage vMotion


. link:../manage/delete-ds.html["Excluir datastores"] Criado nas ferramentas do ONTAP para VMware vSphere.
. Se você habilitou o VASA Provider, selecione *Configurações* > *Configurações do VASA Provider* > *Cancelar registro* em ONTAP tools para cancelar o registro do VASA Provider de todas as instâncias do vCenter Server.
. Remova o adaptador SRA do VMware Live Site Recovery:
+
.. Faça login como administrador na interface de gerenciamento do VMware Live Site Recovery Appliance usando a porta 5480.
.. Selecione *adaptadores de replicação de armazenamento*.
.. Selecione o cartão SRA apropriado e, no menu suspenso, selecione *Excluir*.
.. Confirme se você sabe os resultados da exclusão do adaptador e selecione *Excluir*.


. Remova as instâncias do servidor vCenter integradas ao ONTAP tools for VMware vSphere. Consulte link:../manage/manage-vcenter.html["Gerenciar instâncias do vCenter Server"].
+
Ao remover uma instância do servidor vCenter, as ferramentas do ONTAP podem orientar você durante a limpeza necessária. Se solicitado na caixa de diálogo *Remove vCenter*, selecione *Remove all storage artifacts from this vCenter Server* e *I understand that the associated datastores will no longer be managed by ONTAP tools* e, em seguida, selecione *Force delete*.

+
Antes de usar a opção *Exclusão forçada*, certifique-se de que todos os datastores vVols foram removidos ou migrados, que todos os datastores protegidos foram desprotegidos e que nenhuma tarefa de descoberta está em execução.

+
Se o vCenter Server estiver inacessível durante a exclusão, as ONTAP tools removerão apenas o registro do vCenter Server. Você deve cancelar manualmente o registro do plug-in no VMware vCenter Server.

. Desligue as ferramentas do ONTAP para VMs VMware vSphere do vCenter Server e exclua as VMs.
