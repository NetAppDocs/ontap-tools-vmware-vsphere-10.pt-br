= Modifique as configurações do host ESXi usando as ferramentas do ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Use o painel de ferramentas do ONTAP no VMware vSphere para identificar problemas de configuração, revisar as configurações recomendadas pela NetApp para hosts ESXi selecionados e aplicá-las.

.Antes de começar
O portlet de sistemas host ESXi exibe problemas com as configurações do host ESXi.  Selecione um problema para visualizar o nome do host ou o endereço IP.

.Passos
. Faça login no vSphere Client.
. Na página Atalhos, selecione *NetApp ONTAP tools* na seção Plug-ins.
. Acesse o portlet *Conformidade do host ESXi* no painel Visão geral do ONTAP tools for VMware vSphere plug-in.
. Selecione o link *Aplicar configurações recomendadas*.
. Na janela *Aplicar configurações de host recomendadas*, selecione os hosts para os quais você deseja aplicar as configurações de host recomendadas da NetApp e, em seguida, selecione *Avançar*.
+

NOTE: Você pode expandir o host ESXi para ver os valores atuais.

. Na página Configurações, selecione os valores recomendados conforme necessário.
. No painel de resumo, verifique os valores e selecione *Concluir*. Você pode acompanhar o progresso no painel Tarefas Recentes.
