= Gerencie os limites de armazenamento nas ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode definir limites de armazenamento para receber notificações no vCenter Server quando o volume ou a capacidade agregada atingir um determinado nível.

.Passos
. Faça login no cliente vSphere.
. Na página atalhos, selecione *Ferramentas do NetApp ONTAP* na seção plug-ins.
. No painel esquerdo das ferramentas ONTAP , vá para *Configurações* > *Configurações de limite* > *Editar*.
. Na janela *Editar Limite*, insira os valores desejados nos campos *Quase Cheio* e *Cheio* e selecione *Salvar*.
+

NOTE: Você pode restaurar os valores de limite para os padrões recomendados: 80 para Quase Cheio e 90 para Cheio.
