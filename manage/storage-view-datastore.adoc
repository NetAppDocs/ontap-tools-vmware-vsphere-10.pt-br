= Visualizações de armazenamento ONTAP para datastores em ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Use a página ONTAP Storage na guia *Configurar* para visualizar informações sobre datastore e volume.

.Passos
. No inventário do vSphere Client, selecione o datastore.
. Selecione a guia *Configure* no painel direito.
. Selecione * Ferramentas NetApp ONTAP * > * Armazenamento ONTAP *. A visualização muda de acordo com o tipo de armazenamento de dados.  Veja a tabela abaixo:


|===


| *Tipo de datastore* | *Informação disponível* 


| Datastores NFS | A página *Detalhes do storage* contém backends de storage, agregados e informações de volumes. A página *Detalhes do NFS* contém dados relacionados ao datastore NFS. Observação: se o valor de nconnect for alterado fora do ONTAP tools, o valor exibido no ONTAP tools pode não refletir essa alteração externa. 


| Armazenamentos de dados VMFS | A página *Detalhes do armazenamento* contém informações sobre o backend de armazenamento, o agregado, o volume e a zona de disponibilidade de storage (SAZ). A página *Detalhes da unidade de armazenamento* contém detalhes da unidade de armazenamento. 


| Armazenamentos de dados vVols | Lista todos os volumes. Você pode expandir ou remover o armazenamento do painel de armazenamento do ONTAP . As ferramentas ONTAP não suportam essa visualização para datastores vVols baseados no sistema ASA r2. 
|===
.Resultado
Você pode revisar os detalhes do datastore do lado do ONTAP com base no tipo de datastore selecionado.
