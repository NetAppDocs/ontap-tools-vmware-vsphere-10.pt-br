= Aumente as ferramentas ONTAP e habilite a alta disponibilidade
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Use ONTAP tools Manager para expandir seu appliance e configurar alta disponibilidade (HA). Por padrão, ONTAP tools for VMware vSphere é implantado como uma configuração de nó único, sem HA.

.Antes de começar
* Certifique-se de que seu modelo OVA corresponda à versão do Node 1 (o nó de implantação inicial).
* Habilite o adicionar sem desligamento de CPU e o hot plug de memória no hipervisor. Esses recursos são necessários para aumentar a escala do appliance e habilitar a HA. Para ONTAP tools 10.6 e versões posteriores, esses recursos estão habilitados por padrão. Para versões anteriores, habilite esses recursos antes de aumentar a escala ou habilitar a HA.
* No vCenter Server, defina o nível de automação do Disaster Recovery Service (DRS) como parcialmente automatizado. Retorne ao nível totalmente automatizado após a conclusão da implantação de HA.
+

NOTE: Você só pode aumentar o tamanho do nó, não diminuí-lo. Implantações extra pequenas (XS) limitam determinados serviços.



.Passos
. Inicie o Gerenciador ONTAP tools: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Faça login com suas credenciais de administrador das ONTAP tools.
. Selecione *Editar configurações do appliance* na seção de visão geral.
. Na seção *Configuração*, selecione seu novo tamanho de nó e ative a opção HA para habilitar a Alta Disponibilidade.
. Na página *Configurações do HA*, verifique o seguinte:
+
** A biblioteca de conteúdo reside no mesmo vCenter Server onde as VMs das ONTAP tools serão executadas.
** As VMs das ONTAP tools são implantadas em um cluster ou pool de recursos, não diretamente em um host ESXi.
+

IMPORTANT: Após ativar o HA, você não pode reverter para uma configuração de nó único sem HA.



. Na seção *Configurações de HA*, insira os detalhes de rede para os Nós 2 e 3. ONTAP tools suporta três nós no modo HA.
+
As ONTAP tools preenchem automaticamente a maioria dos campos com as configurações de rede do Node 1. Você pode editar esses valores antes de concluir o assistente. As entradas de endereço IPv6 só estão disponíveis se o IPv6 estiver habilitado no nó de gerenciamento. Certifique-se de que cada host ESXi hospede apenas uma VM do ONTAP tools.

. Analise o resumo e clique em *Salvar*.


.Resultado
O dispositivo inicia o processo de escalonamento e capacitação de HA. Monitore o progresso na página *Visão geral* ou acompanhe o trabalho na visualização *Trabalhos* usando o ID do trabalho.

Se a implantação de alta disponibilidade falhar com o status "Novo", exclua a VM com falha em vCenter e tente novamente.

Consulte a aba *Alertas* para verificar se há avisos ou problemas durante o processo.
