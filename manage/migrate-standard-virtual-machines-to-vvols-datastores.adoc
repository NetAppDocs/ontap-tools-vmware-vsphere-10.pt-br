= Migrar máquinas virtuais para datastores vVols nas ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode migrar máquinas virtuais de datastores NFS ou VMFS para datastores de Virtual Volumes (vVols) para usar o gerenciamento de máquinas virtuais baseado em políticas e outros recursos de vVols.

.Antes de começar
Verifique se o VASA Provider não está em execução em nenhuma das máquinas virtuais que você planeja migrar. Se você migrar uma máquina virtual que esteja executando o VASA Provider para um datastore vVols, você não poderá realizar nenhuma operação de gerenciamento, incluindo ligar as máquinas virtuais que estão em datastores vVols.

.Sobre esta tarefa
Ao migrar de um datastore NFS ou VMFS para um datastore vVols, o vCenter Server utiliza as APIs vStorage para integração de arrays (VAAI) para descarregar os dados movidos de datastores VMFS, mas não de arquivos VMDK NFS. As descarregas VAAI geralmente reduzem a carga do host.

.Passos
. Clique com o botão direito do rato na máquina virtual que pretende migrar e selecione *migrar*.
. Selecione *Change storage only* (alterar apenas armazenamento) e, em seguida, selecione *Next* (seguinte).
. Selecione um formato de disco virtual, uma Política de Armazenamento de VM e um armazenamento de dados vVol que corresponda aos recursos do armazenamento de dados que você está migrando.
. Revise as configurações e selecione *Finish*.
