= Inicie o SSH em outros nós do ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de atualizar o ONTAP tools for VMware vSphere, inicie o SSH em cada um dos outros nós do seu ambiente.

.Antes de começar
Habilite a extensão VASA Provider para sua instância do vCenter Server.

.Sobre esta tarefa
Repita este procedimento em cada nó antes de atualizar.

.Passos
. Faça login no servidor vCenter.
. Localize a máquina virtual do nó do ONTAP tools e inicie o console da web.
. Faça login usando as `maint` credenciais.
. Digite `4` para selecionar *suporte e Diagnóstico*.
. Pressione  `1` Enter para selecionar *Acessar shell de diagnóstico*.
. Entre `y` para continuar.
. Execute o comando  `sudo systemctl restart ssh`.
