= Redefina a senha do usuário do aplicativo em ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Redefina a senha do usuário do aplicativo que o VASA Provider e o SRA usam para se registrar no vCenter Server no ONTAP tools for VMware vSphere.

.Passos
. Abra um navegador da web e acesse `https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Faça login usando as credenciais de administrador configuradas durante a implantação das ferramentas ONTAP .
. Na barra lateral, selecione *Configurações*.
. Na página *Credenciais VASA/SRA*, selecione *Redefinir senha*.
. Digite e confirme a nova senha.
. Selecione *Redefinir* para aplicar a nova senha.
