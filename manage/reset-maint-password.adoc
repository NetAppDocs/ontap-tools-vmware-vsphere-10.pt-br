= Redefina a senha do console de manutenção das ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Durante uma operação de reiniciar do sistema operacional convidado, o menu GRUB exibe uma opção para redefinir a senha do usuário do console de manutenção. Use essa opção para atualizar a senha do usuário do console de manutenção na VM. Após redefinir a senha, a VM reinicia para definir a nova senha. Em uma implantação HA, o sistema atualiza automaticamente a senha nas outras duas VMs após a reinicialização da VM.


NOTE: Para uma implantação HA do ONTAP tools for VMware vSphere, altere a senha do usuário do console de manutenção no nó de gerenciamento do ONTAP tools (node1).

.Passos
. Faça login no vCenter Server
. Clique com o botão direito do mouse na máquina virtual e selecione *Energia* > *Reiniciar SO convidado*. Durante a reinicialização do sistema, a seguinte tela será exibida: image:../media/maint-console-password.png["Repor a palavra-passe do utilizador de manutenção"]
+
Você tem cinco segundos para escolher sua opção. Pressione qualquer tecla para interromper o progresso e congelar o menu GRUB.

. Selecione a opção *Repor a senha do usuário de manutenção*. A consola de manutenção abre-se.
. No console, digite e confirme a nova senha.  Você tem três tentativas.  O sistema reinicia após você inserir a nova senha corretamente.
. Pressione *Enter* para continuar.  O sistema atualiza a senha na máquina virtual.



NOTE: O mesmo menu GRUB aparece quando você liga a máquina virtual. No entanto, você deve usar a opção de redefinição de senha somente com a opção *Reiniciar SO convidado*.
