= Relatórios do ONTAP tools for VMware vSphere
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O plug-in ONTAP tools for VMware vSphere fornece relatórios que ajudam você a monitorar máquinas virtuais e datastores suportados pelo storage ONTAP. Para visualizar os relatórios, selecione o ícone do plug-in ONTAP tools for VMware vSphere na seção de atalhos do vSphere Client e, em seguida, selecione a guia *Reports*.

O relatório de máquinas virtuais lista as máquinas virtuais descobertas que possuem pelo menos um disco em um datastore baseado em ONTAP, juntamente com métricas de desempenho. Ao expandir o registro de uma máquina virtual, você pode visualizar todas as informações do datastore para seus discos.

O relatório de datastores lista os datastores que ONTAP tools for VMware vSphere descobre e que usam storage ONTAP, juntamente com métricas de desempenho.

Você pode usar a opção *Gerenciar colunas* para ocultar ou exibir colunas.
