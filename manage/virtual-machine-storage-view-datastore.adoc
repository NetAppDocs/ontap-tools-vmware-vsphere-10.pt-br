= Veja os detalhes de armazenamento da máquina virtual em ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Use a visualização de storage para ver os vVols associados a uma máquina virtual.


NOTE: Esta visualização aplica-se a VMs com pelo menos um disco proveniente de um armazenamento de dados vVols gerenciado ONTAP tools for VMware vSphere .

.Passos
. No vSphere Client, vá para a máquina virtual.
. Selecione a guia *Monitor* no painel direito.
. Selecione *NetApp ONTAP tools* > *Storage*. Os detalhes de *Storage* aparecem no painel direito. Você pode ver a lista de vVols na máquina virtual.
+
Você pode usar a opção *Gerenciar colunas* para ocultar ou exibir colunas.
