= Visualização do armazenamento da máquina virtual nas ferramentas ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A visualização de armazenamento mostra a lista de vVols que a máquina virtual cria.


NOTE: Esta visualização aplica-se a VMs com pelo menos um disco proveniente de um armazenamento de dados vVols gerenciado ONTAP tools for VMware vSphere .

.Passos
. No vSphere Client, vá para a máquina virtual.
. Selecione a guia *Monitor* no painel direito.
. Selecione *Ferramentas NetApp ONTAP* > *armazenamento*. Os detalhes *Storage* aparecem no painel direito. Você pode ver a lista de vVols que estão presentes na VM.
+
Você pode usar a opção 'Gerenciar colunas' para ocultar ou mostrar diferentes colunas.
