= Adicionar hosts VMware vSphere às ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Adicione novos hosts VMware vSphere ao ONTAP tools for VMware vSphere para que você possa gerenciar e proteger os datastores dos hosts.

.Passos
. Adicione um host ao seu cluster VMware vSphere seguindo as  https://techdocs.broadcom.com/["Documentação técnica Broadcom"].
. Após adicionar o host, acesse o menu principal do ONTAP tools e selecione *Descobrir* no painel de visão geral ou aguarde a conclusão da descoberta de host agendada.


.Resultado
O novo host agora é detectado e gerenciado pelo ONTAP tools for VMware vSphere. Agora você pode gerenciar datastores no host.
